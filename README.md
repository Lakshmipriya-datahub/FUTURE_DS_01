Business Sales Performance Analysis Dashboard

📌Project Overview

Business Sales Performance Analysis focuses on analyzing business sales data to uncover meaningful insights and support data-driven decision-making. Using Microsoft Excel and Microsoft Power BI, the dataset was cleaned, transformed, and visualized into an interactive dashboard.

The analysis highlights revenue trends, top-selling products, category-wise performance, and customer behavior such as churn and retention. The dashboard enables users to quickly understand business performance and make informed decisions.

🎯Business Objectives

A Superstore wants to analyze customer purchasing patterns and business performance to:

Analyze revenue trends over time

Identify top-selling products

Evaluate category-wise performance

Support data-driven decision-making

Build an interactive dashboard for business insights


📂 Dataset Information

The dataset contains key business metrics such as:

Order Date

Sales / Revenue

Product Name

Category

Customer ID

Country

Region

Ship Mode


🛠️ Tools & Technologies Used

Microsoft Excel – Data cleaning & preprocessing

Microsoft Power BI – Dashboard creation & visualization


Project Workflow


1.Data Loading in Excel

The dataset was imported into Excel for initial cleaning and validation.

Key activities:

Inspecting dataset structure

Understanding data types

Identifying missing values

Performing preliminary data checks


2.Data Cleaning & Preparation

Removed duplicate records

Handled missing values

Converted date columns into proper format

Standardized categorical values


3.Power BI Dashboard

An interactive Power BI dashboard was developed to present insights in a business-friendly format.

Dashboard Features:

KPI Cards (Total Revenue, Total Profit, Total Quantity)

Sales Trend Visualization

Category-wise Products Breakdown

Top Products Analysis

Time-based filtering using slicers


The dashboard enables stakeholders to monitor performance and make strategic decisions.

📈 Key Insights

Revenue shows fluctuations with a decline followed by steady growth

Certain products contribute significantly to total sales

Office Supplies contributes the highest revenue
